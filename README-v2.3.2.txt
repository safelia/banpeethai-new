บ้านผีไทย v2.3.2 — Full-art protection cards

เปลี่ยนภาพการ์ดป้องกันเดิมเป็นภาพการ์ดสำเร็จรูปที่ผู้ใช้ส่งมา 3 ใบ:
- ข้าวสารเสก
- สร้อยคอห้อยพระ
- น้ำมนต์

การ์ดทั้งสามใช้ภาพเต็มใบในแคตตาล็อก, ไพ่ในมือ, หน้าพรีวิว และหน้าจั่วการ์ด
การป้องกันใช้ได้กับผีไทยปกติที่ให้เลือกป้องกันได้; ผีอันตรายที่กำหนดว่าป้องกันไม่ได้ยังคงป้องกันไม่ได้
น้ำมนต์ยังคงฟื้นหัวใจอัตโนมัติเมื่อจั่วได้และหัวใจไม่เต็ม ตามกติกาเดิม

ตรวจสอบแล้ว: JSON parse, JavaScript syntax, และเส้นทางภาพที่อ้างอิง
